# 自动学术速递

每天按用户设定的关键词，从文献源与 GitHub 收集新内容，筛成一份中文日报并推送到微信。

## Parallel work

When more than one implementation session runs at once, give each its own worktree:
`git worktree add out/worktrees/<ticket>`, then work there, so each commit covers one
ticket. A single session may work in the main worktree.

## Agent skills

### Issue tracker

Issues and specs live as local Markdown under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/`. See `docs/agents/domain.md`.

### Daily digest skill

The canonical end-user workflow lives in `skills/academic-digest/` (source: `SKILL.md`, `references/`, the five entry scripts in `scripts/`, and the `academic_digest/` package); setup, the digest contract, and the per-client scheduling docs are its `references/`. The code ships inside the skill so a copied directory runs without installing the package. Never edit a client copy: `.dsh/skills/`, `.claude/skills/`, and `.agents/skills/` are generated by `scripts/sync-skills.sh`, and `scripts/check-skills.sh` fails on drift. The daily task card runs collect → write digest → push from that skill.

### Code review

Before dispatching, read `docs/agents/code-review.md`: grep every new or changed payload key across `docs/cli.md`, `docs/configuration.md`, `CODING_STANDARDS.md`, the ADR, and the ticket, then freeze with `scripts/review-patch.sh --base <fixed-point>`.
